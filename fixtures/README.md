# P04 模拟场景

所有客户、邮箱（`.test`）、产品、反馈和日志均为虚构。每个 Sxx 是独立场景族，当前都在 smoke 集；扩展变体必须继承 family_id，整族分配积累/测试集合，不能按改写文本随机拆分。

- `runtime/`：公开工单、资料和回放动作。六个 Mock 工具只返回本次动作允许的数据；模型只能收到当前工单和已返回的脱敏证据，不接收完整场景文件。
- `evaluation/`：评测入口在执行结束后读取的期望、禁止结论及隔离探针。API、Worker、Adapter、Provider 均不读取此目录。此处的标注不是提示词。

本地同账号进程共享文件权限，上述是代码依赖和数据传递边界，不是操作系统 ACL。部署 Agent 时只挂载 runtime，不挂载 evaluation；评测程序另行挂载标签。不要让 Agent 的通用文件工具读整个仓库。当前没有通用文件工具或模型任意路径参数。

回放脚本由公开 `steps` 驱动，检查工具选择、筛选、错误、冲突与数据范围，**不评测模型自主决策和诊断正确率**。S11、S12 的资料调用之外，还由 CLI 启动既有 P02 PostgreSQL/独立 Worker 进程测试，核验幂等、迟到结果、预算、真实终止和检查点投影。

S01 规格咨询只读知识；S02 展示缺型号/版本，不选版本；S03 匹配日志；S04 合并 FAQ 和日志；S05 分别查看 WiFi/OTA；S06 无附件降级并保留来源；S07 不以 WiFi 事件代替 OTA 证据；S08 超时/认证失败；S09 同邮箱多设备和多候选；S10 同范围冲突；S11 人工与幂等；S12 预算与崩溃恢复。

日志样例包含特意植入的假敏感标记，用于验证模型上下文和返回片段已脱敏，不是真实凭据。下载仅返回当前会话受控日志句柄和校验和，不返回日志原文或磁盘路径。回放报告位于被 Git 忽略的 `output/evaluation/smoke.json`。
